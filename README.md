# 🚗 TEAM2 DRIVER SENSE
### 웹캠 기반 실시간 운전자 졸음 및 주의이탈 감지·경고 시스템

> **Detect the Driver. Analyze the Condition. Prevent the Danger.**  
> 운전자를 감지하고, 상태를 분석하고, 위험을 예방한다.

![DRIVER-SENSE 실행 화면](./image/face2.png)

## 📌 Project Overview | 프로젝트 소개

**DRIVER-SENSE**는 Raspberry Pi와 웹캠을 활용해 운전자의 행동을 실시간으로 분석하고, 졸음 및 주의이탈 상황에서 경고를 제공하는 **운전자 상태 감지 시스템**입니다.

눈 감김, 하품, 시선 방향, 고개 움직임, 얼굴 미검출 등 다양한 행동 정보를 조합하여 운전자의 상태를 판단합니다. 분석 결과는 화면과 LED로 표시하며, 외부 누름버튼을 통해 운전자가 경고를 확인하고 상태를 초기화할 수 있도록 구성하고 있습니다.

팀은 **영상 입력 → 행동 분석 → 상태 판단 → 하드웨어 출력 → 사용자 입력**으로 이어지는 전체 동작 흐름을 설계하고, 소프트웨어와 하드웨어가 함께 동작하는 시스템을 개발하고 있습니다.

## ✨ Main Features | 주요 기능

### 01. Driver Behavior Analysis | 운전자 행동 분석

| 기능 | 설명 |
|---|---|
| 👁️ **Eye Closing Detection** | 눈 감김 상태와 지속 시간을 분석하여 졸음 판단에 활용 |
| 🥱 **Yawn Detection** | 하품 발생과 반복 횟수를 분석하여 상태 판단에 활용 |
| 👀 **Gaze Detection** | 눈동자와 시선 방향을 분석하여 주의이탈 여부 판단에 활용 |
| 🙇 **Head Direction Detection** | 고개 방향과 움직임을 분석하여 운전자 행동 파악 |
| 🧑 **Face Detection** | 카메라 영상에서 운전자 얼굴 검출 |
| ⚠️ **Driver Absence Detection** | 얼굴 미검출 상태를 감지하여 운전자 미감지 상황 표시 |

### 02. Status Monitoring & Warning | 상태 모니터링 및 경고

| 기능 | 설명 |
|---|---|
| 🚨 **Driver Distraction Warning** | 시선 및 고개 방향 등의 분석 결과를 바탕으로 주의이탈 경고 |
| 💡 **LED Status Indicator** | 운전자 상태를 LED로 시각적으로 표시 |
| 📷 **Real-time Camera Monitoring** | 실시간 카메라 영상과 상태 정보 제공 |

### 03. User Interaction & Calibration | 사용자 입력 및 보정

| 기능 | 설명 |
|---|---|
| 🔘 **Push Button Alert Reset** | 외부 누름버튼 입력을 통한 경고 확인 및 상태 초기화 |
| 🎯 **Calibration** | 사용자별 얼굴 위치와 눈·시선 등의 기준값 보정 |

> 버튼 입력은 운전자가 경고를 확인했다는 신호로 사용합니다. 초기화 이후에도 카메라 기반 상태 분석을 계속 수행하도록 구성합니다.

## 🚦 Driver Status | 운전자 상태

프로그램은 눈 감김 시간, 하품 횟수, 시선 방향, 고개 방향, 얼굴 검출 여부 등을 조합하여 운전자 상태를 판단합니다.

| 상태 | 의미 |
|---|---|
| 🟢 **NORMAL** | 정상 상태 |
| 🟡 **CAUTION** | 주의 상태 |
| ⚠️ **WARNING** | 경고 상태 |
| 😴 **DROWSY** | 졸음 상태 |
| 👀 **DISTRACTED** | 주의이탈 상태 |
| 🚫 **NO DRIVER** | 운전자 미감지 상태 |

상태 판단에는 사용자별 Calibration 기준값과 행동별 Threshold를 활용합니다. 각 상태의 전환 조건과 누적값 초기화 범위는 반복 테스트를 통해 조정하고 있습니다.

운전자의 여러 행동 정보를 종합하여 상태를 판단하는 핵심 알고리즘 개발에 참여했습니다. 감지 결과가 상태 전환과 외부 장치 제어로 이어지도록 프로그램 로직을 구성했습니다.

- **상태 판단:** 눈 감김, 하품, 시선 및 고개 방향을 조합한 운전자 상태 판단 로직 구현

- **GPIO 연동:** LED 출력과 Push Button 입력을 프로그램에 연결
- **기능 최적화:** 반복 테스트를 통해 오감지·미감지 사례를 확인하고 판단 조건 개선

### 👨‍💻 김동욱 — Computer Vision & Driver Detection

웹캠의 실시간 영상에서 운전자의 얼굴과 행동을 분석하는 영상 처리 기능을 개발했습니다. 사용자별 차이를 고려해 감지 기준을 보정하고, 인식 결과가 하드웨어 동작으로 연결되도록 연동 작업에 참여했습니다.

- **감지 테스트:** 눈 감김과 고개 움직임 등 여러 행동 조건에서 인식 결과 점검

**기능 아이디어 · 동작 로직 분석 · 하드웨어 구성 · 시스템 검증**

운전 중 발생할 수 있는 위험 상황과 사용자 행동을 검토하여 기능 아이디어를 제안했습니다. 구현된 기능이 의도한 시나리오에 따라 동작하는지 확인하며 시스템 개선에 참여했습니다.

- **아이디어 도출:** 졸음과 주의이탈 관련 위험 상황을 구상하고 적용 가능한 기능 제안
- **동작 로직 분석:** 단일 행동과 복합 행동에 따른 상태 판단 및 경고 조건 검토
- **기능 테스트:** 정상·주의·위험 상태 간 전환과 경고 동작 확인
- **회로 구성 참여:** Breadboard와 LED·버튼 등 외부 장치의 연결 상태 점검
- **시스템 검증:** 운전자 감지, 경고 출력, 버튼 입력, 상태 복귀 흐름을 테스트하고 개선 의견 공유

> **팀의 협업 방식**  
> 담당 영역을 중심으로 구현을 진행하고, 감지 결과·상태 전환·회로 동작을 함께 점검했습니다. 발견한 문제는 팀 내에서 공유하고, 알고리즘과 하드웨어의 연결 지점을 조정하며 개선했습니다.

## 🔌 GPIO Configuration | GPIO 구성

현재 테스트에 사용한 GPIO 구성입니다.

| GPIO | 연결 대상 | 역할 |
|:---:|---|---|
| **GPIO17** | 상태 표시 LED | 운전자 상태에 따른 시각적 출력 |
| **GPIO27** | 상태 표시 LED | 운전자 상태에 따른 시각적 출력 |
| **GPIO22** | 상태 표시 LED | 운전자 상태에 따른 시각적 출력 |
| **GPIO23** | Push Button | 경고 확인 및 초기화 입력 |

LED는 상태 판단 결과를 시각적으로 전달하며, Push Button은 운전자가 경고를 확인했다는 입력으로 사용합니다. 상태별 LED 동작과 버튼 입력 후 초기화 범위는 전체 연동 테스트를 통해 점검하고 있습니다.

## ⚠️ Current Limitations & Improvements | 현재 개선 사항

감지 정확도와 상태 전환의 안정성을 높이기 위해 다음 항목을 중심으로 개선을 진행하고 있습니다.

## 🎯 Project Objective | 프로젝트 목표

DRIVER-SENSE는 **Computer Vision 기반 운전자 행동 분석**과 **Raspberry Pi GPIO 하드웨어 제어**를 결합하여, Driver Monitoring System의 기본적인 동작 구조를 구현하는 것을 목표로 합니다.

### 01. 여러 행동을 종합하는 상태 판단

눈 감김, 하품, 시선, 고개 방향, 운전자 미감지 정보를 함께 분석하여 운전자의 상태를 구분합니다.

### 02. 인식 결과와 하드웨어의 연결

영상에서 감지한 결과를 LED 출력과 버튼 입력 처리에 연결하여, 소프트웨어와 외부 회로가 함께 동작하는 시스템을 구성합니다.

### 03. 사용자 차이를 고려한 기준값 보정

Calibration과 Threshold 조정을 통해 사용자별 차이를 반영하고, 반복 테스트로 판단 기준을 개선합니다.

### 04. 개발 과정의 기록과 공유

기획, 구현, 문제 해결, 테스트 과정을 문서화하여 팀의 개발 경험과 개선 근거를 남깁니다.
